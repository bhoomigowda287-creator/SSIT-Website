SSIT Robotics & AI Student Project Website

FILES
- index.html: page content and structure
- style.css: colours, layout, responsive design and project illustrations
- script.js: mobile menu and interactive project detail panels

HOW TO RUN
1. Extract the ZIP file.
2. Open the ssit_robotics_ai_website folder.
3. Double-click index.html. It should open in your web browser.
4. Edit files using Visual Studio Code or another text editor.
5. Save changes and refresh the browser.

IMPORTANT
This is a student-created project template, not an official SSIT website. The department text and project ideas are sample content. Verify all college facts and get permission before presenting it as official. The contact details are intentionally not invented.
